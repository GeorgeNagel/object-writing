# ai-object-writing


## Generating the word list

The bundled word list is generated by a one-off prompt

```
Generate a list of 250 concrete, sensory-rich nouns suitable for object writing exercises.

Object writing is a songwriting technique where you pick an object and write about it using all seven senses (sight, sound, taste, smell, touch, motion, emotion). The goal is to make writing feel grounded and vivid.

Requirements:
- Concrete nouns only — things you can physically encounter
- No abstract concepts (no "love", "freedom", "justice")
- No people or proper nouns
- No locations or places
- Varied categories: household items, nature, food, tools, clothing, vehicles, instruments, etc.
- Mix of single words ("campfire", "hammer") and short noun phrases ("leather glove", "rain gutter", "rusty nail")
- All lowercase

Return ONLY a valid JSON array of strings with no explanation, no markdown, no code fences. Example format:
["campfire", "leather glove", "rain gutter"]`;

Write the 250 concrete nouns to `web/src/data/words.json`
```
